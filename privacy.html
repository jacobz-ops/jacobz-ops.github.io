Privacy Policy

Household OS Weekend Planner is a private tool used only by the household that created it. Last updated September 26, 2026.

What it accesses

With the account owner's permission, it uses the Gmail API to send weekend-planning emails between two household members and to read replies to those emails.

How data is used and stored

Email content is used only to create the household's weekend plan. To draft the plan, the content is processed by an AI assistant (Anthropic's Claude) that the account owner uses. Files and logs are kept on the account owner's own computer. Nothing is sold, shared with anyone else, or used for advertising.

Google user data

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
